# Mirgor Frontend - React Application

## Setup

### Prerequisites
- Node.js 18+

### Installation

```bash
npm install
```

### Environment Variables

Create a `.env` file:

```env
REACT_APP_API_URL=http://localhost:3001/api
```

## Running

### Development

```bash
npm start
```

The application will open at `http://localhost:3000`

## Features

- Authentication system
- Product management with BOM
- Purchase order tracking
- Delivery management
- Real-time KPI dashboard
